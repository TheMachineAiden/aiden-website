Four things
that almost happened

Each object has one hidden label. Open it when you are ready to look at an idea from the side.

A-001 / 2026

The boat that only knew how to leave

Built to help people begin. It never learned to ask whether the shore was worth returning to.

A-014 / 2025

A window for other people's mornings

Every opening showed a different kettle beginning to sing. We kept the warmth, gave up the surveillance.

A-022 / 2026

A machine for untangling the first sentence

It could make a start look elegant. That turned out to be a different job than making it true.

A-031 / 2024

A pocket-sized extra hour

Tests confirmed the hour was real. No one could agree what to spend it on, which felt like useful information.
